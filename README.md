# ระบบจัดเส้นทางและแบ่งงานไรเดอร์ (ข้าวกล่องเดลิเวอรี่)

Angular 19 (standalone + signals) + Leaflet/OpenStreetMap

## รัน
    npm install
    npm start        # http://localhost:4200
    npm run build

## หน้าจอ
- /customers  จัดการลูกค้า (เพิ่ม/แก้/ลบ/ค้นหา) ปักหมุดบ้านบนแผนที่
- /orders     จัดการออเดอร์ (เพิ่ม/แก้จำนวน/ลบ) และปุ่มจำลองออเดอร์พร้อมกัน
- /dispatch   ปุ่มจัดเส้นทาง แผนที่แยกสีไรเดอร์ สรุปรายได้-ต้นทุน-กำไร เส้นเวลาเทียบกับเส้นตาย 12:30
              ปุ่ม "คำนวณใหม่" เสนอเส้นทางทางเลือกอื่น และ "ยืนยัน" เพื่อออกรหัสใบงาน 4 หลัก
- /rider      ไรเดอร์กรอกรหัสใบงาน ดูจำนวนกล่องที่ต้องหยิบ ลำดับจุดส่ง ปุ่มนำทาง Google Maps/โทร/ทำเครื่องหมายส่งแล้ว

## สมมติฐานการคำนวณ (ปรับได้ที่หน้า dispatch > ตั้งค่า)
- ไรเดอร์ออกจากร้านพร้อมกัน 11:30 ต้องถึงทุกจุดก่อน 12:30
- ความเร็ว 30 กม./ชม. ระยะทาง = เส้นตรง x 1.3 (แทนถนนคดเคี้ยว) เวลาส่งต่อจุด 2 นาที
- ค่าส่งต่อไรเดอร์ = 15 + 2 x (กล่องทั้งรอบ) x (กม.ทั้งรอบ) ตามตัวอย่างในโจทย์; ไม่นับขากลับ (เปิดนับได้)
- ไรเดอร์ละไม่เกิน 3 ออเดอร์ (ออเดอร์ละไม่เกิน 3 กล่อง) ขาย 65 ต้นทุน 40
- อัลกอริทึม: simulated annealing แบ่งกลุ่ม + ลองทุกลำดับจุดในกลุ่ม ลงโทษหนักถ้าถึงเลทเส้นตาย
  (src/app/optimizer.ts เป็นฟังก์ชันล้วน ไม่ผูกกับ Angular)

## ข้อจำกัด
- ยังเป็น Front end ล้วน ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ (รหัสใบงานจึงใช้ข้ามเครื่องไม่ได้จนกว่าจะต่อ Back end)
  ชั้นข้อมูลรวมอยู่ใน src/app/store.service.ts ที่เดียว เปลี่ยนเป็น HttpClient ได้โดยไม่แตะหน้าจอ
- พิกัดร้านอยู่ที่ SHOP ใน src/app/models.ts (ตั้งไว้ใกล้ มมส.) ลูกค้าตัวอย่างเป็นข้อมูลสมมติ
- เส้นบนแผนที่เป็นเส้นตรงระหว่างจุด ไม่ใช่เส้นถนนจริง
